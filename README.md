# Clinto Caller (Android)

Rings like an incoming phone call when a "Clinto request" mail notification arrives.
Press **Lift** to hear the request details read aloud.

## Build the APK
**Option A – Android Studio:** File → Open → this folder → wait for sync → Build → Build APK(s).
APK: `app/build/outputs/apk/debug/app-debug.apk`

**Option B – GitHub (no Android Studio):** push this folder to a GitHub repo → Actions tab →
"Build Clinto Caller APK" → download the `ClintoCaller-apk` artifact.

## On the phone
1. Install the APK (allow "install unknown apps").
2. Open Clinto Caller and finish steps 1–4.
3. Tap **Test call now**.
4. Gmail notifications must be ON. Keyword default: `clinto request`.
